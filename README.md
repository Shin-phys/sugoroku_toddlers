# かずの すごろく（数直線すごろく）

3〜7歳向け・家庭用の数直線すごろくです（レベル1〜3は3〜5歳、レベル4・5は6〜7歳）。iPad の Safari でホーム画面に追加すると、オフラインで動きます。
仕様は「数直線すごろくアプリ 仕様書」にもとづいています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| index.html | 画面（タイトル・ゲーム・保護者画面・チェック・使い方） |
| style.css | 見た目 |
| app.js | ゲーム進行、音声、記録、保護者画面、「かずの せん」チェック |
| manifest.json | ホーム画面追加用の設定 |
| sw.js | Service Worker（オフライン用キャッシュ） |
| audio/list.json | 録音音声のキー一覧（初期状態は空 = 合成音声） |
| icons/ | ホーム画面アイコン（180・192・512px） |

外部ライブラリ・CDN・Webフォントは使っていません。ビルドも不要です。

## 公開（GitHub Pages）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードする
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
3. 数分後に表示される URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く

パスはすべて相対パスなので、サブフォルダ（`/<リポジトリ名>/`）でもそのまま動きます。

## iPad への入れ方

1. iPad の Safari で上の URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから一度起動する（この時点で全ファイルが端末に保存される）
4. 機内モードにしてもう一度起動し、動くことを確認する

お子さんがアプリから出ないようにするには、「設定 → アクセシビリティ → アクセスガイド」をオンにし、アプリ起動中にトップボタン（またはホームボタン）を3回押します。

## 更新のしかた

1. ファイルを直す
2. `sw.js` の `VERSION`（例 `v1.0.0` → `v1.0.1`）を必ず上げる。`app.js` の `APP_VERSION` も合わせて上げると保護者画面で確認しやすい
3. GitHub にアップロードする
4. iPad はオンラインの状態でアプリを起動すると、数秒後に新しい版へ切り替わる（遊んでいる途中なら、タイトルに戻ったときに切り替わる）

## 音声

- 初期状態は iPad の日本語合成音声で読み上げます（端末内で動くのでオフラインでも鳴ります）。
- 最初に「はじめる」をタップするまで音は鳴りません（iOS の制約）。
- 録音音声に差し替える場合は、`audio/` に mp3 を置き、`audio/list.json` にキーを書きます。書いたキーだけ録音が使われ、ほかは合成音声のままです。

  ```json
  ["n0","n1","n2","n3","n4","n5","n6","n7","n8","n9","n10","goal","yattane","mataashita","thanks"]
  ```

| キー | 内容 |
| --- | --- |
| n0〜n100 | 数字（ぜろ、いち、に、さん、よん、ご、ろく、なな、はち、きゅう、じゅう…ひゃく） |
| dokoni | どこに とまるかな？（レベル4・5、各ゲームの最初の2回） |
| made10〜made100 | 「〇まで あと いくつ？」（レベル4・5で1回外れたとき） |
| goaldetomaru | ひゃくで とまるよ（レベル4・5で100を超える目が出て外れたとき） |
| goal | ゴール！ |
| pittarigoal | ぴったり ゴール！ |
| stargot | ほし ゲット！ |
| turn_kid / turn_p2 | オレンジさんの ばん／あおさんの ばん（「ふたりで」のとき、番が変わるたび） |
| yattane | やったね！（ゲーム終了） |
| mataashita | また あしたね（1日の上限に達したとき） |
| thanks | ありがとう！（チェックで回答したとき） |
| q2, q3, q5, q7, q8 / q6, q18, q42, q71, q89 | 「〇 は どこかな？」（0〜10版／0〜100版チェックの問題） |

録音を足したり差し替えたりしたときも `sw.js` の `VERSION` を上げてください。

## 仕様書からの実装メモ

### レベル4・5（0〜100・行き先を当てる）

- 上段に0〜100の全体の線、下段に21マスの拡大帯（いまの10区間と次の10区間）。拡大している範囲は全体の線に黄色で示す
- ルーレットの目が出たら行き先のマスをタップする。当たると10の区切りを経由して跳ぶ（36→40→43、弧に「+4」「+3」）。＋10は1回で跳ぶ
- 1回外れたら「40まで あと いくつ？」と最初の弧だけ点線で示す。2回目で正しいマスを光らせる
- レベル5は拡大帯の数字を5と10の倍数（と0・100、いまの位置）だけ表示。止まったマスの数字が現れる
- 「かずの せん」チェックは0〜10版と0〜100版。ずれは線の長さに対する%で記録し、同じグラフに並べる（以前の記録も%に換算して表示）

### 相手の選択（v1.2）

- タイトル画面の「かめさんと」（かめが自動で進む）と「ふたりで」（青い「あおさん」のコマを人が動かす）のどちらかを押して始める。「もう1回」は同じ相手で続ける
- 「ふたりで」は兄弟や保護者が1台を交互に使う。ルーレットもマスのタップも自分で行い、操作は子どもと同じ
- 記録するのはオレンジ（子ども）の手番だけ。保護者画面の記録には「3（ふたり1）」のように、ふたりで遊んだ回数も出る
- 2人とも同じレベルで遊ぶ

### スマホ対応（v1.4）

- iPhone（横向き）でも同じURLで遊べる。画面の高さが500px未満のときだけ、スマホ用の並びに切り替わる
- 上下の帯（声かけ・ルーレット・カード）を薄くして、盤面に高さを回す
- レベル4・5の拡大帯は、スマホでは16マス（5の倍数から始まる。例 35〜50）。iPadは今までどおり21マス
- 0〜20（レベル3）は、スマホではマスのすき間を詰めて、マスをできるだけ大きくする（iPhone 17の横向きで約35〜38pt）
- 縦向きにすると「よこむきに してね」を表示する（数直線は横向きで使う）

### 数の決まり方と星のマス（v1.3）

- レベル1〜3の人の番：ルーレットの数字が0.5秒ごとにランダムな順で切り替わり（同じ数は続かない）、タップした数で止まる。2割の確率で1つすべって別の数になる
- レベル4・5の人の番：1〜9（レベル5は10も）のカードが3枚配られ、1枚を選んで進む。使ったカードは山から補充する
- かめさんは今までどおりランダムに回る
- 星のマス（0〜10は3個、0〜20は4個、0〜100は7個）に、ちょうど止まると星がもらえる。集めた星は画面右上と終了画面に出る
- ゴールにちょうど止まると「ぴったり ゴール！」
- アプリが画面に戻るたびに更新を確かめる（ホーム画面のアプリが裏で止まっていても新しい版に切り替わりやすくした）

### 共通

- 誤タップ：1回目はやさしい音とマスの小さな揺れだけ、2回目以降で正しいマスを光らせる。×や減点はなし
- 自分がいるマスのタップは数え上げとみなさず、誤タップにも数えない
- 数字を読み上げてから約0.8秒は次のタップを受け付けない
- 記録するのは子どもの手番だけ（ゲーム数・誤タップ数・1手の平均時間）
- 保護者画面を開くと、遊んでいる途中のゲームは記録せずに終了する
- レベル提案：同じレベルの直近3ゲームで誤タップの合計が1回以下なら、保護者画面に次のレベルを提案する
- 縦向きにすると「よこむきに してね」を表示する（iOS はアプリ側で向きを固定できないため）
